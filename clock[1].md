## 👋 Bienvenue

The Eternal Clock est un seul fichier HTML. Il affiche une horloge analogique, un compteur de jours depuis une date choisie, et change son éclairage selon votre heure locale. Il nécessite un navigateur et un clic pour activer le son.

---

## ✨ Ce que vous trouverez

**Horloge analogique avec ombres réalistes.**  
Les aiguilles projettent des ombres qui suivent la position du soleil.

**Compteur de jours depuis une date.**  
Affiche le nombre de jours écoulés depuis le lancement du site.

**Éclairage ambiant qui suit le soleil.**  
La lumière et les ombres changent selon l'heure de la journée.

**Tic-tac à chaque seconde.**  
Un son discret est généré à chaque changement de seconde.

**Carillon toutes les heures.**  
Un son plus long est joué au changement d'heure, avec une variante à midi.

---

## 🧭 Comment ça marche

**1. Définissez la date de début.**  
Modifiez la constante `START_DATE` dans le script.

**2. Ouvrez le fichier dans un navigateur.**  
Aucune installation n'est nécessaire.

**3. Cliquez n'importe où sur la page.**  
Cela active le contexte audio pour les sons.

**4. Regardez l'horloge et le compteur se mettre à jour.**  
Tout est calculé localement, en temps réel.

C'est tout. L'horloge tourne toute seule.

---

## 🛠️ Petits coups de main

**Comment changer la date de début ?**  
Modifiez `START_DATE` dans la balise `<script>`.

**Pourquoi je n'entends aucun son ?**  
Cliquez une fois sur la page pour activer l'audio. Les navigateurs bloquent le son avant une interaction.

**Est-ce que ça marche hors ligne ?**  
Oui, après le premier chargement. Aucune connexion n'est requise ensuite.

**Puis-je changer les couleurs ?**  
Oui, modifiez les variables CSS dans `:root` pour adapter les teintes.

## 👋 Welcome

The Eternal Clock is a single HTML file. It shows an analog clock, a counter of days since a set date, and changes its lighting based on your local time. It needs a browser and a click to enable sound.

---

## ✨ What you'll find

**Analog clock with realistic shadows.**  
The hands cast shadows that follow the sun's position.

**Day counter since a chosen date.**  
Shows the number of days elapsed since the site launch.

**Ambient light that follows the sun.**  
Light and shadows change with the time of day.

**Ticking sound each second.**  
A discreet sound is generated on every second change.

**Hourly chime.**  
A longer sound plays on the hour, with a special variant at noon.

---

## 🧭 How it works

**1. Set the start date.**  
Edit the `START_DATE` constant in the script.

**2. Open the file in a browser.**  
No installation is needed.

**3. Click anywhere on the page.**  
This enables the audio context for sounds.

**4. Watch the clock and counter update.**  
Everything is calculated locally, in real time.

That's it. The clock runs by itself.

---

## 🛠️ A little help

**How do I change the start date?**  
Edit `START_DATE` in the `<script>` tag.

**Why don't I hear any sound?**  
Click once on the page to enable audio. Browsers block sound before interaction.

**Does it work offline?**  
Yes, after the first load. No connection is required afterwards.

**Can I change the colors?**  
Yes, edit the CSS variables in `:root` to adjust the tones.
